# Filosofias e Saberes
Periódico trilíngue (PT/ES/EN) de filosofias e saberes — acessível e inclusivo.
Site estático (Eleventy) + painel Sveltia CMS, hospedado gratuitamente no GitHub Pages.

➡️ **Comece pelo `GUIA.md`** (passo a passo em português para colocar no ar e publicar).

- `src/` — conteúdo e templates
- `src/posts/` — publicações (Markdown)
- `src/admin/` — painel de publicação (Sveltia)
- `src/assets/` — CSS e JavaScript
- `.github/workflows/deploy.yml` — publica sozinho a cada mudança
